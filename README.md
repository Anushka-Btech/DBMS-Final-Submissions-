## About This Repository

This repository contains the academic coursework and practical submissions completed as part of the **Database Management Systems (DBMS)** subject during the B.Tech Computer Science and Engineering programme.

It serves as a centralized collection of assignments, laboratory work, database design concepts, SQL implementations, and a full-stack database-driven capstone project.

The repository demonstrates the practical application of relational database concepts, database modelling, normalization, SQL operations, backend integration, and database-driven application development.

### 3. Capstone Project — ExamSphere

**ExamSphere — Online Examination & Result Management System**

ExamSphere is a database-driven web application designed to streamline online examination management, assessment, and result processing.

The system provides separate interfaces and functionality for administrators, faculty members, and students.

#### Key Features

- Role-based authentication and authorization.
- Admin, Faculty, and Student dashboards.
- Student and faculty management.
- Subject and examination management.
- Question creation and management.
- Online examination interface.
- Answer submission and evaluation.
- Result generation and analytics.
- Database-backed application workflows.
- API-based communication between frontend and backend.

#### Technology Stack

| Layer | Technologies |
|---|---|
| Frontend | React, TypeScript, Vite |
| Styling | Tailwind CSS |
| Backend | Node.js, Express.js, TypeScript |
| Database | MySQL |
| Database Connectivity | mysql2 |
| Validation | Zod |
| Authentication | bcrypt, Cookie Parser |
| Testing | Vitest |
| Deployment | Vercel, Render, Railway |
